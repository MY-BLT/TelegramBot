# Telegram Bot

## Learning

> ### Get the token

>> Get the bot token from the botfather in telegram and add it to the .env file by name **BOT_TOKEN**.

> ### Write first bot by telebot

>> Create a bot that have just the welcome message by command start and polling.
---
> ### Working by commands in the bot

>> Send message and other things by the input commands.

> ### Regex in the input text

>> Using regexp=r"" in the input of message_handler.

> ### Chat_types for message_handler

>> Use the private chat_types to respond to all the messages.
---
> ### Keyboards:

> #### 1.ReplyKeyboards

>> These are used for sending the showed text in the box in bottom of the bot chat window.

> #### 2.InlineKeyboards

>> These are used for the message and are shown under the message.
>> Usage of them is by calling not by sending message.
